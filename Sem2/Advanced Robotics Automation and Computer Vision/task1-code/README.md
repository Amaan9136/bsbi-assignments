# Task 1 - Drone Crop Disease Classification

MobileNetV2-based plant disease classifier, fine-tuned on PlantVillage with
augmentation intended to approximate drone-captured aerial imaging conditions.

## Project layout

```
task1_package/
├── requirements.txt
├── main.py                  # CLI entry point (VS Code / terminal)
├── src/
│   ├── config.py            # Config dataclass, seeding
│   ├── data.py               # Dataset loading, transforms, DataLoaders
│   ├── model.py               # MobileNetV2 construction, checkpoint loading
│   ├── train.py               # Training loop, checkpoint saving
│   ├── evaluate.py            # Metrics, confusion matrix, top confusions
│   ├── inference.py           # Single-image and batch inference
│   ├── plotting.py            # All matplotlib figure generation
│   └── logging_setup.py       # Shared logger configuration
└── notebook/
    └── Task1_Drone_Crop_Disease_Classification.ipynb   # Thin runner, same src/ calls
```

## Running in VS Code (recommended for local development)

1. Open this folder (`task1_package/`) as your VS Code workspace root.
2. Create and activate a virtual environment:
   ```
   python -m venv .venv
   source .venv/bin/activate      # on Windows: .venv\\Scripts\\activate
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the full pipeline:
   ```
   python main.py --epochs 8 --batch-size 32
   ```
   Useful flags:
   - `--epochs N` - number of training epochs (default 8)
   - `--batch-size N` - DataLoader batch size (default 32)
   - `--lr X` - learning rate (default 3e-4)
   - `--output-dir PATH` - where checkpoints/figures/results are written (default `outputs/`)
   - `--skip-plots` - skip figure generation, useful for a quick smoke test
5. To run the same pipeline interactively instead, open
   `notebook/Task1_Drone_Crop_Disease_Classification.ipynb` in VS Code with the
   Jupyter extension installed, and select your `.venv` as the kernel.

## Running in Google Colab

1. Zip this entire `task1_package/` folder (or download it as a zip if that is
   how you received it).
2. Open a new Colab notebook, or upload
   `notebook/Task1_Drone_Crop_Disease_Classification.ipynb` directly via
   File > Upload notebook.
3. Set the runtime to GPU: Runtime > Change runtime type > GPU.
4. Run the first code cell. It detects Colab automatically; if `src/` is not
   already present in the Colab filesystem, it prompts you to upload the zip
   from step 1 and extracts it.
5. Run the remaining cells in order. Training time depends on the Colab GPU
   tier you have access to; the free tier is sufficient to complete a full run
   but may be slower or subject to usage limits compared to Colab Pro.
6. The final cells save a checkpoint and `results_summary.json` to `outputs/`,
   and optionally copy that folder to Google Drive so it persists after the
   runtime disconnects (mount Drive when prompted).

## Where your report numbers come from

After a full run, `outputs/results_summary.json` contains the exact accuracy,
macro precision/recall/F1, training time and parameter count to quote in the
report. `outputs/` also contains the five figures
(`class_distribution.png`, `augmented_samples.png`, `training_curves.png`,
`confusion_matrix.png`, `inference_samples.png`) referenced in the report's
Execution and Testing subsection. None of these are generated by this
codebase in advance - they only exist after you actually run it.
